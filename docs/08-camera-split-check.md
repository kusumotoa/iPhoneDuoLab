# 実機で確かめる: 内側カメラを使う app と使わない app が並んだとき

**使う app と使わない app が Split View で並んだとき、使わない側の、内側カメラの領域はアクティブになるか。** シミュレータにはカメラがなく、確かめられません（[04-camera.md](04-camera.md)）。実機で確かめる手順です。

## 1. 2 つの app を入れる

同じ app を、別々のバンドル ID と表示名で 2 つ入れます。

```sh
cd tools/measure
xcrun devicectl list devices                        # 実機の識別子
./install-two-apps.sh device <デバイスの識別子> <Team ID>
```

| 表示名 | バンドル ID |
| --- | --- |
| Duo カメラ側 | `com.kusumotoa.iPhoneDuoLab.camera` |
| Duo 観察側 | `com.kusumotoa.iPhoneDuoLab.observer` |

## 2. 役割を決める

両方で「**カメラの並走テスト（実機用）**」を開き、上のスイッチで役割を選びます（app ごとに保存されます）。

| app | 役割 |
| --- | --- |
| Duo カメラ側 | 「カメラを使う側」 |
| Duo 観察側 | 「使わない側（観察のみ）」 |

## 3. 画面の見方

<img src="assets/shots/camera-split/lab-screen.png" width="250">

| 表示 | 意味 |
| --- | --- |
| 赤い枠 | アクティブな領域 |
| 青い枠 | 非アクティブな領域 |
| 一覧 | 各領域の、アクティブかどうかと、位置・大きさ |
| 記録 | `isActive` が変わった時刻（ミリ秒まで） |
| 「コピー」 | 役割・ヒンジ・記録を、メモに貼れる形でコピー |

内側カメラの領域は、**内側ディスプレイで開いたとき**に出ます。

## 4. 確かめる場面

内側ディスプレイで開き、2 つの app を Split View で並べます（一方を開き、Dock やホーム画面のアイコンを、もう一方の画面の端へドラッグ）。

| 場面 | やること | 見るもの |
| --- | --- | --- |
| **A. 基準** | 2 つとも、カメラを開始しない | 両方で、内側カメラの領域が**非アクティブ**か |
| **B. 最重要** | カメラ側で「内側カメラを開始」 | **観察側の領域が、アクティブに変わるか** |
| **C. 停止** | カメラ側で「内側カメラを停止」 | 観察側が、非アクティブに戻るか |
| **D. 画面の状態** | カメラを動かしたまま、カメラ側を Split View から外す | カメラが止まったとき、観察側はどうなるか |
| **E. ほかの app** | 観察側だけを開き、標準のカメラ app などで内側カメラを使う | 別の app のカメラ使用でも、観察側が変わるか |
| **F. 目で見る** | B の状態で、カメラの領域の付近を見る | 画面が暗くなる・欠けるか。赤い枠と一致するか |

## 5. B の結果の読み方

| B の結果 | 意味 | 対応 |
| --- | --- | --- |
| 観察側は**変わらない** | アクティブ状態は app ごと | カメラを使わない app は、領域を気にしなくてよい |
| 観察側も**アクティブに変わる** | アクティブ状態は端末全体 | カメラを使わない app も、領域を避ける。`reservedRegions` に追従する |
| どちらも変わらない | `isActive` がカメラと連動していない | F で、画面の欠けを目で確かめる |

## 詰まったとき

- **「内側カメラが見つかりません」**: シミュレータでは必ず出ます。実機で出るなら、端末と OS のビルドを控えてください
- **「カメラの許可がありません」**: 設定アプリで、「Duo カメラ側」にカメラを許可します（バンドル ID ごとに必要）
- **シミュレータで画面だけ確かめる**: `./install-two-apps.sh sim`。許可のダイアログは、`xcrun simctl privacy <UDID> grant camera <バンドル ID>` で消えます

この Lab が見ているのは、SwiftUI の `reservedRegions(kind: .occlusion, options: [.includeInactive])` の `isActive` です。UIKit の `isActive` が同じ値になるかは、実機で確かめていません。
